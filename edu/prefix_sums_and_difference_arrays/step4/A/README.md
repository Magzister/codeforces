Дан массив a. Поступают запросы прибавления константы на отрезках этого массива. В конце нужно вывести получившийся массив.

Входные данные
Первая строка входных данных содержит одно целое число n (1≤n≤106) — количество элементов массива a.

Вторая строка входных данных содержит n целых чисел ai (−109≤ai≤109) — элементы массива a.

Третья строка входных данных содержит одно целое число q (1≤q≤106) — количество запросов прибавления на отрезке.

Каждая из последующих q строк содержит по три целых числа li, ri и di (1≤li≤ri≤n, −109≤di≤109) — границы отрезка массива, на котором надо прибавить константу, а также сама константа.

Выходные данные
Выведите n чисел — элементы массива после выполнения всех операций.
