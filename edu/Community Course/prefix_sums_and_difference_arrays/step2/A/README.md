Дан массив a. Поступают запросы поиска суммы на отрезке. Вам необходимо на них отвечать.

Входные данные
Первая строка входных данных содержит одно целое число n (1≤n≤106) — количество элементов массива.

Вторая строка входных данных содержит n целых чисел ai (−109≤ai≤109) — элементы массива a.

Третья строка входных данных содержит одно целое число q (1≤q≤106) — количество запросов поиска суммы на отрезке.

Каждая из последующих q строк содержит по два целых числа li и ri (1≤li≤ri≤n) — границы отрезка массива, на котором нужно найти сумму.

Выходные данные
Для каждого запроса в отдельной строке выведите сумму элементов на соответствующем отрезке массива (включая границы).
