Вам дана перестановка∗ p длины n.

Найдите перестановку q длины n, которая минимизирует количество пар (i,j) (1≤i≤j≤n) таких, что pi+pi+1+…+pj=qi+qi+1+…+qj.

∗
Перестановкой длины n является массив, состоящий из n различных целых чисел от 1 до n в произвольном порядке. Например, [2,3,1,5,4] — перестановка, но [1,2,2] не перестановка (2 встречается в массиве дважды) и [1,3,4] тоже не перестановка (n=3, но в массиве встречается 4).

Входные данные
Каждый тест состоит из нескольких наборов входных данных. Первая строка содержит одно целое число t (1≤t≤104) — количество наборов входных данных. Далее следует описание наборов входных данных.

Первая строка каждого набора входных данных содержит число n (1≤n≤2⋅105).

Следующая строка содержит n разделенных пробелом целых чисел p1,p2,…,pn (1≤pi≤n) — перестановка p длины n.

Гарантируется, что сумма n по всем наборам входных данных не превосходит 2⋅105.
